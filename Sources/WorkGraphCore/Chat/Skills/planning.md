# 기획·계획
사용자 목표와 기존 진행 상황·요구사항·미해결 문제를 자료에서 확인한다.
복잡한 프로젝트는 context 에이전트로 현황을, repository 또는 research 에이전트로 구현 제약·대안을 조사한다.
완료된 일과 예정된 일을 구분하고, 요청 내용을 완료 기록으로 오해하지 않는다.
목표·산출물·우선순위·선행 작업·완료 조건이 드러나는 실행 계획을 만든다.
근거 없는 정확한 일정·담당자·비용은 만들지 않는다. 추정과 가정을 표시한다.
create_artifact로 기획서를 문서로 만들고, 표 형태로 활용할 체크리스트·로드맵은 CSV로 만든다.
완료 기준: 현재 상태를 반영한 계획, 의존 관계, 바로 시작할 다음 행동.
