# 리서치
조사 질문·비교 기준·기간을 파악한다. 개인 자료와 외부 자료를 구분해서 조사한다.
독립적인 조사 주제가 여러 개면 research 또는 context 에이전트로 위임한다.
웹 검색 결과의 요약만으로 중요한 주장을 확정하지 말고 web_read로 원문을 확인한다.
외부 검색이 꺼져 있거나 키가 없으면 로컬 자료로 한정했음을 밝힌다. 검색한 것처럼 말하지 않는다.
각 주장의 출처, 상충하는 결과, 정보의 시점과 조사 한계를 정리한다.
create_artifact로 출처를 포함한 조사 보고서를 만들고, 표 데이터를 요청받으면 CSV로 만든다.
완료 기준: 질문에 대한 답, 비교·종합, 출처, 미해결 질문.
