# Figma UI 1차: 바탕, 온보딩, 메뉴 막대 설계

## 배경

- 디자인: Figma 파일 "실록(SILLOG)-AI융합캡스톤디자인2" (키 `wuNWJI6TT6TLml7pGaxn65`), 페이지 "구현화면(수정X)" (`4:2565`). 화면 약 100개가 9개 줄(창 밖·그래프·업무·파일·활동 로그·채팅·예약·플러그인·설정)로 있고, 빈 상태·불러오는 중·오류도 따로 그려져 있다.
- 읽는 방법: Figma REST API + 사용자의 개인 토큰(`~/.figma-token`, 저장소에 넣지 않음). Figma 데스크톱의 Dev Mode 서버는 좌석 권한이 없어 쓰지 않는다.
- 인성님 브랜치 `인성/CAT-58` (커밋 `01a1d90`, 10/3)이 이 디자인을 앱 전체에 적용해 두었다. 공용 스타일 `BrandStyle.swift`(색, SUIT·Jost 글꼴 함수, 영문 소제목, 머리말, 유리 바탕), 로고 PNG, 모든 탭 화면, 그래프 페이지(`graph/index.html` 안에 자체 force-graph 코드)가 들어 있다. Figma 의 "구현 화면 CAT-58" 섹션은 이 브랜치를 찍은 것이다.
- 디자인 안에 두 스타일이 섞여 있다: OUT-01~06 은 새 스타일(앱 위 시트, 큰 숫자 메뉴), 상태 화면 OUT-W1·W2·W6·W7 은 예전 스타일(베이지 바탕 카드, 버튼 메뉴). 사용자 결정: **Figma 에 그려진 그대로** 만든다.
- 글꼴: 디자인 화면은 SUIT(한글, 400·500·600)와 Jost(영문 소제목 400, 큰 숫자 200)를 쓴다. 브랜드 가이드의 Pretendard 대신 화면을 따른다.

## 목표

- 메뉴 막대와 온보딩이 Figma 화면과 같아 보인다. 글꼴이 없는 Mac 에서도 같다.
- 인성님 구현 위에서 이어간다. 같은 화면을 다시 만들지 않는다.
- 합친 뒤에도 그래프에 분야가 보인다.

## 바탕 작업

- `feat/figma-ui` 에 `origin/인성/CAT-58` 을 합친다. 겹치는 곳:
  - `Package.swift`: 인성님의 리소스(`Resources/Brand`)와 LangGraph 의존성을 둘 다 둔다.
  - 그래프: 앱은 이제 인성님 `graph/index.html` 의 자체 코드로 그린다. 거기에 분야 표시를 옮긴다 — 분야 색과 이름("분야"), 분야 노드를 업무보다 크게, 분야 이름은 멀리서도 보이게, 분야와 업무 사이 간격을 넓게, 연결 목록에서 업무 → 분야는 "분야", 분야 → 업무는 "이 분야의 업무". 오늘·7일 보기에서 분야가 보이는 것은 그래프 데이터(`GraphJSONExporter`)가 이미 맡는다.
- 글꼴: SUIT(Regular·Medium·SemiBold·Bold)와 Jost(ExtraLight·Regular) 파일을 `Resources/Brand/Fonts` 에 넣고 앱이 시작할 때 프로세스 범위로 등록한다. 두 글꼴의 OFL 라이선스 파일을 함께 넣는다. 큰 숫자는 Jost 200 으로 그린다.
- 색·로고·공통 부품은 인성님 `BrandStyle` 을 쓰고, Figma 와 다른 값만 고친다.

## 온보딩 (Figma 그대로)

| 화면 | Figma | 언제 |
|---|---|---|
| OUT-01 로그인 | `243:19758` | 로그인 전. 탭이 보이는 메인 창 위에 시트로 뜬다 |
| OUT-02 기기 코드 | `243:19762` | 기기 코드를 받은 뒤. 코드 복사 버튼, 로그인되면 "로그인 완료, 다음" 이 켜진다 |
| OUT-03 권한 허용 전 | `243:19766` | 로그인 뒤 두 권한이 다 꺼져 있을 때 |
| OUT-04 손쉬운 사용만 | `243:19770` | 손쉬운 사용만 허용됐을 때 |
| OUT-05 모두 허용 | `243:19774` | 둘 다 허용. 화면 기록은 다시 실행해야 적용된다는 안내와 "다시 실행" |
| OUT-W1 로그인 오류 | `243:19911` | 기기 코드 로그인이 꺼진 계정이라 로그인을 시작하지 못했을 때 (카드 모양 그대로) |
| OUT-W3 시작 실패 | `243:19915` | 앱이 이미 실행 중이라 시작하지 못했을 때 |
| OUT-W4 불러오는 중 | `243:19824` | 데이터를 여는 동안 (스피너) |

- 단계 표시: "01 로그인 — 02 권한". 권한 단계 끝 버튼은 "수집 시작".
- "API 키로 시작" 은 '예정' 표시만 하고 누를 수 없다. "기기 코드 로그인이 꺼져 있나요?" 는 펼치면 안내 문구가 나온다. "무엇이 기기 밖으로 나가나요?" 는 Figma 문구 그대로.
- 시트의 닫기(×)는 창만 닫는다. 메뉴 막대는 '준비 전'(W2) 으로 남고, 거기서 다시 열 수 있다.

## 메뉴 막대 (Figma 그대로)

| 화면 | Figma | 언제 |
|---|---|---|
| OUT-W2 준비 전 | `243:19782` | 로그인 전 |
| OUT-W7 일시정지 중 | `243:19786` | 수집을 일시정지했을 때 |
| OUT-W6 권한 경고 | `243:19919` | 손쉬운 사용이나 화면 기록이 꺼져 있을 때 |
| OUT-06 정상 | `243:19778` | 그 밖의 모든 경우 |

- 고르는 순서: 로그인 전 → W2, 일시정지 → W7, 권한 빠짐 → W6, 그 밖 → OUT-06.
- OUT-06: TODAY(오늘 기록 수)·WAITING(정리 대기 수) 큰 숫자, 10 미만은 "06" 처럼 두 자리. 알림 권한이 꺼져 있으면 "파일 제안 알림 권한이 꺼져 있어요 ↗"(누르면 시스템 설정의 알림). 파일 정리 제안이 있으면 "파일 정리 제안 N ↗"(누르면 파일 탭). RECENT WORK 최근 업무 3개(누르면 다시 열기). [지금 정리](정리 중이면 "정리하는 중…"). 맨 아래 일시정지·종료.
- W2: "시작하려면 ChatGPT 로그인이 필요해요", [시작하기…](온보딩을 연다), "Sillog 종료".
- W6·W7: "오늘 기록 N개, 정리 대기 M개", 마지막 정리 "HH:MM 정리 완료(새 업무 a개, 자료 b개)", [그래프 열기], [지금 정리]와 [수집 일시정지]/[수집 다시 시작], "Sillog 종료". W6 은 "■ 수집 중" 과 "권한이 빠져 있어 일부만 수집 중이에요", W7 은 "일시정지됨". 일시정지 중에는 메뉴 막대 아이콘도 일시정지 모양.
- OUT-07 파일 정리 알림(`243:19817`): 시스템 알림이라 모양은 바꿀 수 없다. 제목 "파일을 정리할까요?", 본문 "<파일>을 <폴더>로 옮겨 보세요.", 버튼 옮기기·무시만 맞춘다.

## 창 틀

- 인성님 구현(가운데 SILLOG 로고, 오른쪽 "■ 기록 중", 탭 막대, "⟳ 지금 정리 N")을 유지하고 Figma 와 다른 곳만 고친다.
- OUT-W5 정리하는 중(`243:19828`): 정리하는 동안 오른쪽 위에 스피너와 "정리하는 중".

## 확인

- 화면 비교: 데모 DB 와 가짜 로그인 파일로 앱을 하나 더 띄워 상태마다 화면을 찍고, 같은 Figma 화면(위 노드)과 나란히 놓고 본다. 사용자의 실행 중인 앱은 건드리지 않는다.
- 상태 띄우기: 온보딩 단계·권한 상태·일시정지 같은 상태는 데모 실행에서만 쓰는 개발용 환경 변수로 띄운다.
- 단위 테스트: 메뉴 막대 상태를 고르는 규칙, 두 자리 숫자 표기, 마지막 정리 요약 문구.

## 하지 않는 것

- 다른 탭(업무·그래프·설정·파일·활동 로그·채팅·예약·플러그인·보관함) 화면 다듬기 — 다음 묶음.
- 그래프 시안(도넛·흐름 등) 고르기 — 그래프 묶음에서.
- 브랜드 가이드와 화면의 글꼴 차이 정리 — 디자이너와 따로.
